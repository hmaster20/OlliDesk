# Coding Bench — задачи

Формат задачи:
<task_name>/
├── repo/ # исходный код (копируется в work-каталог)
├── tests/ # тесты (копируются поверх repo/; для go — могут быть в repo/)
├── task.md # описание для модели

text

`tests/bench/runner.py` копирует `repo/` + `tests/` во временный каталог,
запускает `AgentLoop` с coder-моделью, затем `run_tests`. Задача считается
пройденной, если тесты зелёные.

Добавить задачу: создать каталог с `repo/`, `task.md` и (опционально)
`tests/`; язык определяется по расширениям в `repo/`.
