# Fix off-by-one in parser

Файл `repo/parser.py` содержит функцию `parse_numbers(text)`, которая
должна возвращать список чисел из строки с разделителем `,`.

Текущая реализация теряет последний элемент (цикл идёт по `parts[:-1]`).

Исправь баг через `apply_patch`, чтобы все тесты проходили.

Тесты: `python -m pytest tests/ -q`
